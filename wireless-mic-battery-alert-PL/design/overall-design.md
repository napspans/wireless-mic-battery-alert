# 全体設計

## プロジェクト目標

ワイヤレスマイクの無音状態を監視し、電池切れや接続異常の兆候をユーザーへ通知する Windows デスクトップアプリケーションを提供する。  
成功条件は、常駐監視・通知・設定保存・EXE配布が実用レベルで安定動作すること。

## アーキテクチャ概要

- `main.py`: アプリ全体の起動、設定読込、監視制御、通知連携、GUI/トレイ連携
- `monitor.py`: 入力デバイス監視、無音判定、状態遷移コールバック
- `notifier.py`: builtin/custom 音声の解決と再生
- `settings.py`: 設定ファイルの読込・保存
- `gui.py`: 設定画面とユーザー操作
- `tray.py`: タスクトレイ常駐とメニュー操作
- `build.spec`: PyInstaller による EXE 化設定

依存方向は、UI/トレイ/通知/監視が `main.py` に集約され、各下位モジュール同士は直接結合しない。

## 技術的制約

- 言語: Python
- 実行環境: Windows
- GUI: tkinter / ttk / sv_ttk
- 音声再生: pygame
- 音声入力監視: sounddevice, numpy
- 配布形式: PyInstaller による `.exe`（onedir 想定）

## 設計方針

- モジュール責務を明確に分離し、設定・通知・監視・UI の境界を保つ
- 実行環境差分（スクリプト実行 / PyInstaller 実行）は共通の解決方針を持たせる
- UI変更は既存の視覚言語を崩さず、動作変更と混在させない
- ビルド再現性に関わる情報はコード変更とは別に記録し、追跡可能にする

## テスト方針

- 単体レベル: 設定読込保存、パス解決、例外系の破綻がないことを確認する
- 統合レベル: 監視開始停止、通知音再生、GUI保存、トレイ連携を確認する
- 受け入れレベル: EXE 起動、設定永続化、builtin 音再生、エラー表示、スタートアップ登録を確認する
- 手動確認を中心とし、ビルド前後で再現手順を明文化する
