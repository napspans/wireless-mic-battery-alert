# Phase 8: 最終ビルドと受け入れ確認

## 目的

Phase 7 で是正した内容を前提に最終 EXE ビルドを実施し、第三者レビューのチェックリストを含む受け入れ確認を完了する。

## スコープ

- 対象:
  - Windows ビルドを安定実行するための補助手順整備
  - PyInstaller による最終 onedir ビルド
  - EXE 起動後の動作確認
  - 配布物としての最低限の受け入れ確認
- 対象ファイル:
  - `wireless-mic-battery-alert-eng/build.spec`
  - `wireless-mic-battery-alert-eng/dist/` 配下の生成物
  - 必要に応じたビルド関連補助ファイル
- スコープ外:
  - 新たな機能追加
  - 第三者レビュー未指摘の大規模リファクタリング

## テスト計画

- 検証項目
  - Windows 環境で `.exe` 生成に成功する
  - EXE起動・トレイアイコン表示確認
  - 設定変更後、再起動しても設定が保持される
  - `config.json` が意図した場所に生成される
  - builtin アラート音が正常に再生される
  - デバイス未接続時のエラーダイアログが表示される
  - スタートアップ登録が有効時に動作する
- 手動確認手順
  1. 必要であれば Windows 実行用の補助手順またはスクリプトを整備する
  2. Windows 環境で PyInstaller により最終 onedir ビルドを実行する
  2. 生成 EXE を起動し、設定変更と再起動を行う
  3. builtin 音声再生、トレイ表示、エラー表示を確認する
  4. スタートアップ登録を有効化して動作を確認する
- 合格基準
  - 第三者レビューの EXE ビルド後チェックリストをすべて満たす
  - ビルド生成物に未解決の不具合が残っていない
