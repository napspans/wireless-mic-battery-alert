# Step 34: デフォルト通知音設定を更新

## 目的

ビルド前の仕様調整として、初期状態で使用される通知音の既定値を希望の組み合わせへ変更する。  
設定ファイル未作成時の内部既定値と GUI 上の初期表示が一致する状態にする。

## 作業対象ファイル

- `wireless-mic-battery-alert-eng/settings.py`
- `wireless-mic-battery-alert-eng/gui.py`

## 変更仕様

- 通知音の既定値を `Error` に変更する
- 一時停止音の既定値を `Marimba` に変更する
- 監視停止音の既定値を `Marimba` に変更する
- 監視再開音の既定値は `Notify 11` を維持する
- 設定ファイルが存在しない場合に読み込まれる内部既定値と、GUI が設定未保存時に表示するフォールバック値を一致させる

## インターフェース制約

- 音声指定形式は既存どおり `builtin:...` を使う
- 既存ユーザーの保存済み設定は上書きしない

## 完了条件

- [ ] 新規設定時の `alert_sound_path` が `builtin:error` になっている
- [ ] 新規設定時の `pause_sound_path` が `builtin:marimba` になっている
- [ ] 新規設定時の `monitor_stop_sound_path` が `builtin:marimba` になっている
- [ ] 新規設定時の `monitor_resume_sound_path` が `builtin:notify_11` になっている
- [ ] GUI 上の各通知音初期表示が内部既定値と一致している

## 動作確認手順

1. 設定ファイルがない状態を前提に、既定値読込結果を確認する
2. GUI の通知音関連 UI 初期表示を確認する
3. 保存済み設定がある場合は、その値が優先される構造を壊していないことを確認する

## 注意事項

- 既存の音声選択肢そのものは変更しない
- 変更対象は既定値のみで、新たな通知イベント追加は行わない
