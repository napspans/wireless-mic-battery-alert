# Step 23: main.py — ステータスサウンド実装

## 目的

`monitor.py` に追加した `on_snoozed` / `on_snooze_resume` コールバックを `main.py` で実装し、
一時停止・再開・停止の各タイミングでサウンドを再生する。

## 作業対象ファイル

- `wireless-mic-battery-alert-eng/main.py`

## 変更仕様

### _on_alert の変更

最後のアラートスレッドへの参照を保持するため、`__init__` に `_last_alert_thread` を追加し、
`_on_alert` でスレッドを保存する：

```python
# __init__ に追加
self._last_alert_thread: threading.Thread | None = None

# _on_alert 内のスレッド起動部分を変更
t = threading.Thread(target=self._notifier.play_sound, args=(sound_path, volume), daemon=True)
self._last_alert_thread = t
t.start()
```

### _on_snoozed の追加

最後のアラート音の完了を待ってから一時停止サウンドを再生する。
`pause_sound_enabled` が False の場合は何もしない：

```python
def _on_snoozed(self):
    if not self._config.get("pause_sound_enabled", True):
        return
    pause_sound_path = self._config.get("pause_sound_path", "builtin:notify_04")
    volume = self._config.get("alert_volume", 80)

    def _play():
        t = self._last_alert_thread
        if t is not None:
            t.join()
        try:
            self._notifier.play_sound(pause_sound_path, volume)
        except Exception:
            pass

    threading.Thread(target=_play, daemon=True).start()
```

### _on_snooze_resume の追加

```python
def _on_snooze_resume(self):
    volume = self._config.get("alert_volume", 80)
    threading.Thread(
        target=self._notifier.play_sound,
        args=("builtin:notify_11", volume),
        daemon=True,
    ).start()
```

### _toggle_monitor の変更

監視停止時にサウンドを再生する（`stop()` の直後）：

```python
def _toggle_monitor(self):
    if self._monitor.is_running:
        self._monitor.stop()
        volume = self._config.get("alert_volume", 80)
        threading.Thread(
            target=self._notifier.play_sound,
            args=("builtin:notify_11", volume),
            daemon=True,
        ).start()
    else:
        try:
            self._monitor.start()
        except Exception as exc:
            self._on_stream_error(str(exc))
```

### AudioMonitor の生成変更

`run()` 内の `AudioMonitor` 生成時にコールバックを渡す：

```python
self._monitor = AudioMonitor(
    self._config,
    on_alert=self._on_alert,
    on_snoozed=self._on_snoozed,
    on_snooze_resume=self._on_snooze_resume,
)
```

## 注意事項

- 監視停止サウンドは `_quit()` 経由（アプリ終了）では鳴らさない。`_toggle_monitor` 経由のみ
- `_on_snooze_resume` はサウンドを例外キャッチなしで直接スレッド起動してよい（`play_sound` 内で `logger.error` によるハンドリング済み）
- `_on_snoozed` 内の `play_sound` は例外をキャッチすること（daemon スレッドからの呼び出しのため）
