# Step 3: `notifier.py` 設計改善

## 目的

`notifier.py` から不要なエントリと不適切な設定依存を除去し、モジュール境界を明確にする。

## 作業対象ファイル

- `wireless-mic-battery-alert-eng/notifier.py`
- `wireless-mic-battery-alert-eng/main.py`

## 現状の問題点

1. `_BUILTIN_MAP` に `"builtin:default"` → `default_alert.wav` のエントリが残存している
   - このキーを参照するコードはなく、不要
2. `play_sound` メソッド内で `settings.load()` を直接呼んでいる
   - `Notifier` が設定管理モジュールに依存しており、責務の境界が崩れている
   - 音量は呼び出し側から渡すべき

## 実装内容

### `notifier.py` の変更

#### 1. `"builtin:default"` エントリを削除する

```python
# 変更前
_BUILTIN_MAP = {
    "builtin:chime": os.path.join(_BASE_DIR, "assets", "alert_chime.wav"),
    "builtin:error": os.path.join(_BASE_DIR, "assets", "alert_error.wav"),
    "builtin:marimba": os.path.join(_BASE_DIR, "assets", "alert_marimba.wav"),
    "builtin:default": os.path.join(_BASE_DIR, "assets", "default_alert.wav"),  # ← 削除
}
```

```python
# 変更後
_BUILTIN_MAP = {
    "builtin:chime": os.path.join(_BASE_DIR, "assets", "alert_chime.wav"),
    "builtin:error": os.path.join(_BASE_DIR, "assets", "alert_error.wav"),
    "builtin:marimba": os.path.join(_BASE_DIR, "assets", "alert_marimba.wav"),
}
```

#### 2. `play_sound` のシグネチャを変更し、`settings` 依存を除去する

```python
# 変更前
import settings

def play_sound(self, sound_path: str) -> None:
    ...
    volume = settings.load().get("alert_volume", 80)
    sound.set_volume(volume / 100.0)
```

```python
# 変更後
# import settings を削除

def play_sound(self, sound_path: str, volume: int = 80) -> None:
    ...
    sound.set_volume(volume / 100.0)
```

### `main.py` の変更

`_on_alert` メソッドで `volume` を取得して `play_sound` に渡すよう変更する。

```python
# 変更前
threading.Thread(target=self._notifier.play_sound, args=(sound_path,), daemon=True).start()

# 変更後
volume = self._config.get("alert_volume", 80)
threading.Thread(target=self._notifier.play_sound, args=(sound_path, volume), daemon=True).start()
```

## 完了条件

- [ ] `notifier.py` の `_BUILTIN_MAP` に `"builtin:default"` エントリが存在しないこと
- [ ] `notifier.py` が `settings` モジュールをインポートしていないこと
- [ ] `play_sound` のシグネチャが `(self, sound_path: str, volume: int = 80)` になっていること
- [ ] `main.py` の `_on_alert` で `volume` を取得して `play_sound` に渡していること
