# Step 1: プロジェクト初期セットアップ

## 目的

前身プロジェクト `mic_battery_alert_eng/` のファイルを新プロジェクト `wireless-mic-battery-alert-eng/` にコピーし、動作確認できる状態にする。

## 作業対象ファイル

コピー先: `wireless-mic-battery-alert-eng/`

## 実装内容

以下のファイル・ディレクトリを `/home/napspans/workspace/mic_battery_alert_eng/` から `/home/napspans/workspace/wireless-mic-battery-alert/wireless-mic-battery-alert-eng/` へコピーする。

コピー対象:
- `main.py`
- `monitor.py`
- `notifier.py`
- `settings.py`
- `gui.py`
- `tray.py`
- `theme.py`
- `requirements.txt`
- `assets/` ディレクトリ（中身ごと）

コピーコマンド例:
```bash
cp /home/napspans/workspace/mic_battery_alert_eng/main.py \
   /home/napspans/workspace/mic_battery_alert_eng/monitor.py \
   /home/napspans/workspace/mic_battery_alert_eng/notifier.py \
   /home/napspans/workspace/mic_battery_alert_eng/settings.py \
   /home/napspans/workspace/mic_battery_alert_eng/gui.py \
   /home/napspans/workspace/mic_battery_alert_eng/tray.py \
   /home/napspans/workspace/mic_battery_alert_eng/theme.py \
   /home/napspans/workspace/mic_battery_alert_eng/requirements.txt \
   /home/napspans/workspace/wireless-mic-battery-alert/wireless-mic-battery-alert-eng/

cp -r /home/napspans/workspace/mic_battery_alert_eng/assets/ \
      /home/napspans/workspace/wireless-mic-battery-alert/wireless-mic-battery-alert-eng/assets/
```

コピー後、以下を確認する:
- `wireless-mic-battery-alert-eng/` に全ファイルが存在すること
- `requirements.txt` の内容を出力して確認すること（中身を報告すること）
- `__pycache__/` はコピー不要

## 完了条件

- [ ] 7つの `.py` ファイルが `wireless-mic-battery-alert-eng/` に存在する
- [ ] `assets/` ディレクトリと `.wav` ファイル4本が存在する
- [ ] `requirements.txt` が存在し、内容を報告済み
- [ ] `__pycache__/` が含まれていないこと

## 注意事項

- `AGENTS.md` はコピー不要（既に存在する）
- `config.json` はコピー不要（初回起動時に自動生成される）
- ファイルを削除する操作は不要。コピーのみ行うこと
