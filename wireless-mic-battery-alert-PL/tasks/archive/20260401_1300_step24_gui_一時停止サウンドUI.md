# Step 24: gui.py — 通知設定タブに一時停止サウンドUI追加

## 目的

通知設定タブに「一時停止サウンド」セクションを追加し、
ユーザーが一時停止サウンドのオン/オフとサウンドファイルを設定できるようにする。

## 作業対象ファイル

- `wireless-mic-battery-alert-eng/gui.py`

## 変更仕様

### モジュールレベルの定数追加

既存の `_SOUND_OPTIONS` / `_COMBO_TO_PATH` と同じ構造で、一時停止サウンド用の定数を追加する：

```python
_PAUSE_SOUND_OPTIONS = ["内蔵: Notify 04", "内蔵: Chime", "内蔵: Error", "内蔵: Marimba", "カスタム..."]
_PAUSE_COMBO_TO_PATH = {
    "内蔵: Notify 04": "builtin:notify_04",
    "内蔵: Chime": "builtin:chime",
    "内蔵: Error": "builtin:error",
    "内蔵: Marimba": "builtin:marimba",
}
_PAUSE_PATH_TO_COMBO = {v: k for k, v in _PAUSE_COMBO_TO_PATH.items()}
```

### 通知設定タブへの追加

既存の「テーマ」行（row=4）の下に以下を追加する：

| row | 内容 |
|-----|------|
| 5 | ヘッドラインラベル「一時停止サウンド」（`_make_headline_label` を使用） |
| 6 | ボディラベル「一時停止サウンド」 + チェックボックス「有効にする」 |
| 7 | ボディラベル「サウンドファイル」 + コンボ + テスト再生ボタン |

- チェックボックスが OFF のとき、row 7 のコンボとテスト再生ボタンを `state="disabled"` にする
- チェックボックスのトグル時に row 7 の enabled/disabled を切り替え、かつ `_auto_save()` を呼ぶ

### _init_pause_sound_ui メソッドの追加

`_init_sound_ui` と同様に、`config["pause_sound_path"]` からコンボの初期値を設定する。
カスタムパスの場合は「カスタム...」を選択してパス入力欄を表示する（アラート音UIと同構造）。

### _get_pause_sound_path_value メソッドの追加

`_get_sound_path_value` と同様に、コンボの選択値からパス文字列を返す。

### _on_save の変更

以下を追加する：

```python
self._config["pause_sound_enabled"] = self._pause_sound_enabled_var.get()
self._config["pause_sound_path"] = self._get_pause_sound_path_value()
```

### destroy の変更

追加した変数（`_pause_sound_enabled_var`、`_pause_sound_combo_var` 等）を `None` に設定する。

なし

- [ ] 「有効にする」チェックボックスが `config["pause_sound_enabled"]` の値で初期化される
- [ ] サウンドファイルのコンボが `config["pause_sound_path"]` の値で初期化される

## 注意事項

- テスト再生ボタンの実装は `_test_play_sound` と同様のパターンで行うこと
- カスタムパス入力欄（参照ボタン含む）も `_browse_sound` と同様のパターンで追加してよい
- 既存の `_SOUND_OPTIONS` には `"内蔵: Notify 04"` は含まれていない。追加不要（アラート音コンボはそのまま）
