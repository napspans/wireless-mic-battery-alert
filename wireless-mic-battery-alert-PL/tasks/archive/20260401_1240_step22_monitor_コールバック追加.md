# Step 22: monitor.py — on_snoozed / on_snooze_resume コールバック追加

## 目的

`AudioMonitor` にスヌーズ発動・スヌーズ解除のタイミングを外部に通知するコールバックを追加する。
これにより `main.py` 側でそれぞれのタイミングにサウンドを再生できるようになる。

## 作業対象ファイル

- `wireless-mic-battery-alert-eng/monitor.py`

## 変更仕様

### __init__ の変更

引数に `on_snoozed` と `on_snooze_resume` を追加し、インスタンス変数に保持する：

```python
def __init__(self, config: dict, on_alert: callable,
             on_snoozed: callable = None,
             on_snooze_resume: callable = None):
```

### _monitor_loop の変更

**スヌーズ発動箇所**（`self._snoozed = True` の直後）でコールバックを呼ぶ：

```python
if auto_snooze_enabled and self._auto_snooze_count >= snooze_limit:
    self._snoozed = True
    if self._on_snoozed:
        self._on_snoozed()
```

**スヌーズ解除箇所**（`self._snoozed = False` の後、`self._resume_start = None` の後）でコールバックを呼ぶ：

```python
if self._snoozed and (now - self._resume_start) >= resume_sec:
    self._snoozed = False
    self._auto_snooze_count = 0
    self._resume_start = None
    if self._on_snooze_resume:
        self._on_snooze_resume()
```

## インターフェース制約

```python
def __init__(self, config: dict, on_alert: callable,
             on_snoozed: callable = None,
             on_snooze_resume: callable = None):
```

既存の `AudioMonitor(self._config, on_alert=self._on_alert)` という呼び出し側は変更不要（デフォルト引数のため）。

## 完了条件

- [ ] `__init__` に `on_snoozed` / `on_snooze_resume` 引数が追加されインスタンス変数に保持されている

- [ ] スヌーズ解除時（`_snoozed = False` の後）に `_on_snooze_resume` が呼ばれる
- [ ] 既存の `on_alert` のみを渡す呼び出しが引き続き動作する（デフォルト引数 `None`）
- [ ] `python3 -m py_compile monitor.py` でエラーがないこと

## 注意事項

- コールバックは `_monitor_thread`（daemon スレッド）から呼ばれる。コールバック内での例外は呼び出し側（main.py）の責任でハンドリングする想定のため、monitor.py 側で try/except は不要
