# Step 31: UI改善（スライダー・チェックボックス・保存シンボル）

## 目的

実機テストで報告された以下3点の UI 問題を修正する。

1. **シークバーがダークモードに反している**: `tk.Scale` はWindowsネイティブレンダリングのため、ダークモードでつまみが白/グレーになる
2. **チェックボックスがダークモードに反している**: `tk.Checkbutton` も同様
3. **設定保存シンボルが見えない**: `ttk.Label` が背景色を継承しないためダークモードで視認しにくい

`sv_ttk` が既に導入されており、`ttk.Scale` / `ttk.Checkbutton` は sv_ttk が自動でダークモードスタイルを適用するため、ウィジェットを置き換えるだけで解決できる。

## 作業対象ファイル

- `wireless-mic-battery-alert-eng/gui.py`

---

## 変更仕様

### 1. シークバーを `tk.Scale` → `ttk.Scale` に置き換える

`_build_settings_form` 内の `self._volume_scale` 生成箇所を `ttk.Scale` に変更する。

- 維持するパラメータ: `from_=0`, `to=100`, `orient=tk.HORIZONTAL`, `variable=self._volume_var`
- `ttk.Scale` は `showvalue`, `resolution`, `background`, `foreground`, `troughcolor`, `length` を受け付けないため除去する
- `resolution=1`（整数値強制）の代替として、`command` に `lambda v: self._volume_var.set(round(float(v)))` を追加する
- `grid` 配置と `sticky=tk.EW` は維持する
- `bind("<ButtonRelease-1>", self._auto_save)` は維持する

### 2. チェックボックスを `tk.Checkbutton` → `ttk.Checkbutton` に置き換える

`_make_checkbutton` メソッド内のウィジェット生成を `ttk.Checkbutton` に変更する。

- `ttk.Checkbutton` のパラメータは `text`, `variable`, `command` のみとする
- `background`, `foreground`, `activebackground`, `activeforeground`, `selectcolor`, `highlightthickness`, `borderwidth`, `anchor` は不要なので除去する
- `self._checkbuttons.append(checkbutton)` は維持する（後述の `_apply_visual_theme` 変更で対応）

### 3. `_apply_visual_theme` からの不要なテーマ更新処理を除去する

sv_ttk ウィジェットはテーマ切り替えで自動スタイルが適用されるため、手動更新コードを除去する。

- `for checkbutton in self._checkbuttons:` ブロック全体を除去する
- `if hasattr(self, "_volume_scale"):` ブロック全体を除去する

### 4. 保存ステータスラベルを `ttk.Label` → `tk.Label` に変更する

`_build_button_area` 内の `self._save_status_label` を `tk.Label` に変更し、テーマ色を明示的に指定する。

- `background=colors["bg"]`, `foreground=colors["secondary_label"]` を設定する
- `font=theme.FONTS["caption"]` は維持する

また `_apply_visual_theme` に以下を追加する:

- `if hasattr(self, "_save_status_label"):` で `self._save_status_label.configure(background=colors["bg"])` を呼ぶ

## 完了条件

- [ ] ダークモード時にシークバーのつまみが丸型・バーが細く表示される（sv_ttk スタイル）
- [ ] ライトモードでもシークバーが正常に表示される
- [ ] ダークモード時にチェックボックスがダークモードデザインに合った表示になる
- [ ] 設定を変更したとき、ウィンドウ下部に `✓ 保存しました` などの保存シンボルが視認できる
- [ ] テーマ切り替え（ライト⇔ダーク）後もシークバー・チェックボックスが正しく表示される
- [ ] ボリューム値（0〜100 整数）が正しく動作する

## 動作確認手順

1. `python main.py` を起動し、設定画面を開く
2. 「通知設定」タブを開き、全体音量のシークバーを確認する（つまみが丸く・バーが細い）
3. 各チェックボックスがダークモードデザインに合って表示されることを確認する
4. 何らかの設定を変更し、ウィンドウ下部に保存シンボルが表示されることを確認する
5. 「詳細設定」タブのテーマを「light」に切り替え、手順2〜4を再確認する
6. テーマを「dark」に戻して正常動作を確認する

## 注意事項

- `_checkbuttons` リストは残したままにする（`_apply_visual_theme` でループは除去するが、リスト自体は残す）
- `ttk.Checkbutton` は `anchor` を受け付けないため除去すること
- `_make_checkbutton` の引数 `colors: dict` はシグネチャとして維持してよい（呼び出し側の変更が不要になる）
- 変更は `gui.py` のみ。`theme.py` は変更不要
