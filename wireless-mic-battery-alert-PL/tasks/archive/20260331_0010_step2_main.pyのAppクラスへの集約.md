# Step 2: `main.py` の `App` クラスへの集約

## 目的

`main.py` のモジュールレベルグローバル変数と関数群を `App` クラスに集約し、コードの見通しを改善する。

## 作業対象ファイル

- `wireless-mic-battery-alert-eng/main.py`

## 現状の問題点

`main.py` は以下のモジュールレベルグローバルを持つ:

```python
_config, _monitor, _tray, _notifier, _gui, _gui_lock, _gui_starting,
_quit_event, _last_alert_time, _alert_lock, _ALERT_DISPLAY_SEC
```

これらをグローバルで管理しているため、関数間の依存が暗黙的になっている。

## 実装内容

以下のルールに従って `App` クラスを実装すること。

### 注意事項

- `_on_alert` 内の `sound_path` のデフォルト値は `"assets/default_alert.wav"` のままにしておく（Step 3 で除去する）
- グローバル変数 `_BASE_DIR` も `self._base_dir` に変換すること
- コールバックの渡し方: `TrayIcon` や `AudioMonitor` へのコールバックは `self._xxx` メソッドをそのまま渡す（lambda 不要）
- インポートは変更しない
