# Step 10: ボタン・ステータスエリアのデザイン完成

## 目的
`gui.py` のボタンエリアとステータス表示を Apple HIG 精神に基づいて整備し、
フェーズ2 UIデザイン刷新の仕上げを行う。

## 作業対象ファイル
- `wireless-mic-battery-alert-eng/gui.py`

## 変更仕様

### 1. ボタンエリアの余白改善（`_build_button_area`）
- `btn_frame.pack(...)` の `padx` / `pady` を定数ベースに変更：
  - `padx=_PAD_OUTER, pady=(_PAD_INNER, _PAD_OUTER)`

### 2. 監視ボタンの幅統一
- `self._monitor_btn` に `width=12` を設定し、「監視 開始」「監視 停止」切替時に幅が変わらないようにする

### 3. 保存フィードバックラベルの改善
- `self._save_status_label` を `ttk.Label` に変更（現在 `tk.Label`）
- フォントを `theme.FONTS["caption"]` に変更
- `foreground` は `_on_save` 内で `theme.COLORS["light"]["success"]` を参照して設定する
  - ただしテーマに応じて切り替える：`get_colors(resolved_theme)["success"]` を使用
  - `resolved_theme` は `self._config["theme"]` から `get_system_theme()` で解決する

### 4. ステータスラベルの色をテーマカラーに対応させる（`_update_status`）
- 停止中: `get_colors(resolved_theme)["secondary_label"]`
- スヌーズ中: `theme.COLORS` の `warning` カラー（`get_colors(resolved_theme)["warning"]`）
- 監視中: `get_colors(resolved_theme)["success"]`
- `resolved_theme` は `self._config.get("theme", "system")` から解決する

## インターフェース制約
- 外部インターフェース変更なし

## 完了条件
- [ ] `btn_frame.pack()` の余白が `_PAD_OUTER` / `_PAD_INNER` ベースになっている
- [ ] 監視ボタンに `width=12` が設定されている
- [ ] `_save_status_label` が `ttk.Label` + `FONTS["caption"]` になっている
- [ ] 保存フィードバックの文字色が `get_colors()["success"]` を参照している
- [ ] `_update_status` のステータス色が `get_colors()` を参照している
- [ ] `python3 -m py_compile gui.py` が成功する

## 注意事項
- このステップ完了後、フェーズ2の全ステップが完了となる
- `_save_status_label` の `text="✓"` 表示の仕組み（`after(1500, ...)` によるクリア）は変更しない
