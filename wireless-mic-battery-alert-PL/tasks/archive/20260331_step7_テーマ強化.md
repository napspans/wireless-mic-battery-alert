# Step 7: テーマ強化 — カラー定数・フォント階層定義

## 目的
Apple Human Interface Guidelines の精神に基づくUIデザイン刷新の基盤として、
`theme.py` にカラーパレット定数・フォント階層定義・スタイル設定を整備する。
後続のStep 8〜10がこの定数を参照することで、デザインの一貫性を担保する。

## 作業対象ファイル
- `wireless-mic-battery-alert-eng/theme.py`

## 変更仕様

### 1. カラーパレット定数の定義（`COLORS` 辞書）
ライトテーマ・ダークテーマ別に以下のカラーを定数化する：
- `bg`: ウィンドウ背景（ライト: `#f5f5f7`、ダーク: `#1c1c1e`）
- `surface`: カード・フレーム面（ライト: `#ffffff`、ダーク: `#2c2c2e`）
- `border`: 区切り線（ライト: `#d1d1d6`、ダーク: `#38383a`）
- `label`: 通常ラベル文字色（ライト: `#1c1c1e`、ダーク: `#f2f2f7`）
- `secondary_label`: 補助テキスト（ライト: `#6e6e73`、ダーク: `#98989d`）
- `accent`: アクセントカラー（テーマ共通: `#0071e3`）
- `success`: 成功色（テーマ共通: `#34c759`）
- `warning`: 警告色（テーマ共通: `#ff9f0a`）

### 2. フォント定数の定義（`FONTS` 辞書）
視覚階層に対応したフォント設定を定数化する：
- `title`: ウィンドウタイトル等（Meiryo UI, 13pt, bold）
- `headline`: セクション見出し（Meiryo UI, 11pt, bold）
- `body`: 通常ラベル・入力（Meiryo UI, 10pt）
- `caption`: 補助テキスト・ステータス（Meiryo UI, 9pt）

### 3. スタイル適用の強化（`apply_theme` 関数）
既存の `sv_ttk.set_theme()` 呼び出しに加え、以下を追加：
- `TLabel` に `body` フォントを適用
- `TButton` にパディング（ipadx=12, ipady=4）を設定
- `TNotebook.Tab` にパディング（padx=12, pady=6）を設定
- `TSeparator` の背景色を `border` カラーで設定

### 4. ヘルパー関数の追加
- `get_colors(theme: str) -> dict`: テーマ名（"light" / "dark"）を受け取り該当の `COLORS` 辞書を返す

## 完了条件
- [ ] `COLORS` 辞書がライト・ダーク両テーマ分定義されている
- [ ] `FONTS` 辞書が4段階（title/headline/body/caption）定義されている
- [ ] `apply_theme()` でボタン・タブのパディングが設定されている
- [ ] `get_colors(theme)` 関数が "light"/"dark" を引数として動作する
- [ ] 既存のインポート（`from theme import apply_theme`, `from theme import get_system_theme`）が引き続き動作する

- `sv_ttk` の既存テーマ機能を無効化・置換しない（上書きではなく追加）
