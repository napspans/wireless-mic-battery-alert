# Step 36: EXE受け入れ確認

## 目的

Windows で生成された最終 `.exe` が、配布物として必要な最低限の動作要件を満たすことを確認する。  
第三者レビューのビルド後チェックリストと Phase 8 の受け入れ基準を実機で消化する。

## 作業対象ファイル

- `wireless-mic-battery-alert-eng/dist/` または Windows ローカル出力先の最終生成物
- 必要に応じて `wireless-mic-battery-alert-eng/build_windows.bat`
- 必要に応じて `wireless-mic-battery-alert-eng/BUILD_WINDOWS.md`

## 変更仕様

- 生成済みの Windows `.exe` を起動し、主要機能を実機で確認する
- 設定保存、builtin 音再生、トレイ表示、エラーダイアログ、スタートアップ登録を確認する
- 受け入れ確認結果を報告書に整理する

## インターフェース制約

- 受け入れ確認が目的であり、仕様変更や追加実装は行わない
- 問題が見つかった場合は修正せず、まず事象と再現条件を報告する

## 完了条件

- [ ] EXE起動・トレイアイコン表示確認ができている
- [ ] 設定変更後、再起動しても設定が保持される
- [ ] `config.json` が意図した場所に生成される
- [ ] builtin アラート音が正常に再生される
- [ ] デバイス未接続時のエラーダイアログが表示される
- [ ] スタートアップ登録が有効時に動作する

## 動作確認手順

1. Windows で生成済み `.exe` を起動する
2. トレイ表示、設定変更、再起動後の保持を確認する
3. builtin 音声再生を確認する
4. デバイス未接続時のエラー表示を確認する
5. スタートアップ登録を有効化して動作を確認する

## 注意事項

- 実機確認は Windows 側で行う
- 問題があれば症状、再現手順、発生箇所を報告書に明記する
