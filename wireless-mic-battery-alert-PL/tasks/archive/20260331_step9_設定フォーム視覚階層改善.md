# Step 9: 設定フォームの視覚階層改善

## 目的
`gui.py` の設定タブ（監視設定・通知設定・詳細設定）内のレイアウトを改善し、
ラベル・入力欄の視覚的階層と余白を Apple HIG 精神に基づいて整備する。
`_PAD_ROW` / `_PAD_OUTER` / `_PAD_INNER` を活用して余白を統一する。

## 作業対象ファイル
- `wireless-mic-battery-alert-eng/gui.py`

## 変更仕様

### 1. Notebook の余白更新（`_build_settings_form` 冒頭）
- `notebook.pack(...)` の `padx` / `pady` を定数ベースに変更：
  - `padx=_PAD_OUTER, pady=(_PAD_INNER, _PAD_INNER)`

### 2. 各タブ内フレームに内側余白を追加
3つのタブフレーム（`monitor_frame`, `notify_frame`, `detail_frame`）それぞれに
内側余白のためのラッパーを作成する：
- 各タブフレームの直下に `ttk.Frame(tab_frame, padding=(_PAD_INNER, _PAD_INNER))` を作成し、
  `pack(fill=tk.BOTH, expand=True)` で配置する
- 以降のウィジェット配置はこのラッパーフレームに対して行う

### 3. グリッド行間パディングの統一
全タブ内の全 `.grid(...)` 呼び出しの `pady` を `_PAD_ROW` に変更する

### 4. ラベルフォントの差別化
各タブ内のラベル（`ttk.Label`）に `font=theme.FONTS["body"]` を明示的に設定する
（現状は `apply_theme` 経由で設定されているが、将来の変更に対して明示する）

### 5. セクション見出しの追加（各タブ先頭）
各タブの先頭行（row=0の上）にセクション見出しラベルを追加する：
- 監視設定タブ: 「デバイスと検知パラメータ」
- 通知設定タブ: 「アラートと通知」
- 詳細設定タブ: 「スヌーズ動作」
- フォント: `theme.FONTS["headline"]`
- `columnspan=2`, `pady=(_PAD_ROW[0], _PAD_INNER)`, `sticky=tk.W`
- 既存ウィジェットの `row` 番号を1つずつずらす

## インターフェース制約
- 外部インターフェース変更なし

## 完了条件
- [ ] `notebook.pack()` の余白が定数ベースになっている
- [ ] 各タブ内にラッパーフレームが追加されている
- [ ] 全 `.grid()` の `pady` が `_PAD_ROW` に統一されている
- [ ] 各タブ先頭にセクション見出しラベルが追加されている（`FONTS["headline"]`）
- [ ] `python3 -m py_compile gui.py` が成功する

## 注意事項
- ボタンエリアはStep 10で対応するため、変更しない
- `_PAD_ROW` は `(6, 6)` のタプルであり、`pady=_PAD_ROW` として直接使用できる
- ラッパーフレームを挟むと `columnconfigure` の対象が変わるため、ラッパーフレームにも `columnconfigure(1, weight=1)` を設定すること
