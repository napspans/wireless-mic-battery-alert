# Step 35: Windows最終ビルド用の補助スクリプトと手順を整備

## 目的

このセッションから Windows ネイティブビルドを直接実行できないため、Windows 環境で確実に最終ビルドを実施できる補助スクリプトと手順を整備する。  
ビルド担当者が Windows 側でそのまま実行できる状態を作り、Step 35 本体の再実施につなげる。

## 作業対象ファイル

- `wireless-mic-battery-alert-eng/build.spec`
- `wireless-mic-battery-alert-eng/requirements.txt`
- `wireless-mic-battery-alert-eng/requirements-lock.txt`
- `wireless-mic-battery-alert-eng/` 配下の Windows ビルド補助ファイル

## 変更仕様

- Windows 側で依存導入と PyInstaller ビルドを実行できる補助スクリプトまたは手順ファイルを追加する
- 実行コマンド、前提環境、生成物確認箇所が一目で分かる形にする
- Linux / WSL 上で生成された非 Windows 産物は最終成果物として扱わないことを明記する
- Windows 側の担当者が追加判断なしで実行できる粒度まで具体化する

## インターフェース制約

- `build.spec` の意図を崩す変更は行わない
- 新規機能追加や仕様変更は行わない
- 補助ファイルは Windows で実行しやすい形式を優先する

## 完了条件

- [ ] Windows 側で実行できる補助スクリプトまたは手順ファイルが追加されている
- [ ] 依存導入、PyInstaller 実行、生成物確認の流れが明確になっている
- [ ] Windows ビルド時の前提条件と確認ポイントが報告書に整理されている

## 動作確認手順

1. Windows 実行用の補助スクリプトまたは手順ファイルを作成する
2. 内容を確認し、依存導入から `.exe` 生成確認までの流れが通っていることを確認する
3. Windows 側で別途実行すべきコマンドと確認箇所を報告書に整理する

## 注意事項

- 本ステップでは Windows 実機上でのビルド実行そのものは完了条件に含めない
- 実際の `.exe` 生成と受け入れ確認は、この準備完了後に継続して扱う
