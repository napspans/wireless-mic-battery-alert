# Step 26: main.py — 手動監視開始時のサウンド再生

## 目的

タスクトレイの右クリックメニューから手動で「監視 開始」した際に、
再開サウンド（`builtin:notify_11`）を再生する。

現状、`_toggle_monitor()` の「監視 停止」側にはサウンドが実装されているが、
「監視 開始」側にはサウンドがない。これを追加する。

## 作業対象ファイル

- `wireless-mic-battery-alert-eng/main.py`

## 変更仕様

`_toggle_monitor()` の `else`（監視開始）ブロックに、監視開始成功後のサウンド再生を追加する。

現在：

```python
def _toggle_monitor(self):
    if self._monitor.is_running:
        self._monitor.stop()
        volume = self._config.get("alert_volume", 80)
        threading.Thread(
            target=self._notifier.play_sound,
            args=("builtin:notify_11", volume),
            daemon=True,
        ).start()
    else:
        try:
            self._monitor.start()
        except Exception as exc:
            self._on_stream_error(str(exc))
```

変更後（`monitor.start()` が成功した場合のみサウンドを再生）：

```python
    else:
        try:
            self._monitor.start()
        except Exception as exc:
            self._on_stream_error(str(exc))
            return
        volume = self._config.get("alert_volume", 80)
        threading.Thread(
            target=self._notifier.play_sound,
            args=("builtin:notify_11", volume),
            daemon=True,
        ).start()
```

## 完了条件

- [ ] タスクトレイから「監視 開始」を実行したとき `builtin:notify_11` が再生される
- [ ] `monitor.start()` が例外を送出した場合はサウンドが再生されず、`_on_stream_error()` が呼ばれる
- [ ] `python3 -m py_compile main.py` でエラーがないこと

## 注意事項

- アプリ起動時の自動監視開始（`run()` 内の `monitor.start()`）ではサウンドを鳴らさない（変更不要）
- 再生するサウンドは停止・再開ともに同じ `builtin:notify_11`
