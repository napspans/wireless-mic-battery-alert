# Step 25: gui.py — 監視ボタン移動 + 通知設定タブスクロール対応

## 目的

2点の UI 修正を行う：

1. 「監視 開始/停止」ボタンをタブ外のステータス行（「○ 停止中」ラベル付近）に移動し、タブ切り替えで消えない位置に固定する
2. 通知設定タブをスクロール可能にし、追加項目が画面外にはみ出す問題を解消する

## 作業対象ファイル

- `wireless-mic-battery-alert-eng/gui.py`

## 変更仕様

### 1. 監視ボタンの移動

**`_build_waveform_area()` の変更:**

separator の下に `_status_label` を単独で pack する代わりに、ステータス行フレームを作り、
左に `_status_label`、右に `_monitor_btn` を配置する：

```
[separator]
[ ● 監視中 (左寄せ)    [監視 停止] (右寄せ) ]
```

- `_monitor_btn_var` と `_monitor_btn` の生成をこのメソッドに移す

**`_build_button_area()` の変更:**

`_monitor_btn_var` / `_monitor_btn` の生成を削除し、`_save_status_label` のみを残す。
ボタンエリアのフレーム自体はそのまま残してよい（`_save_status_label` の表示場所として使う）。

### 2. 通知設定タブのスクロール対応

`_build_settings_form()` の通知設定タブ（notify_frame）のみ、コンテンツを Canvas + Scrollbar によるスクロール可能なフレームに入れる。

実装パターン:

```python
# notify_frame 内にスクロール構造を作る
canvas = tk.Canvas(notify_frame, highlightthickness=0)
scrollbar = ttk.Scrollbar(notify_frame, orient="vertical", command=canvas.yview)
scrollable_inner = tk.Frame(canvas)

scrollable_inner.bind(
    "<Configure>",
    lambda e: canvas.configure(scrollregion=canvas.bbox("all"))
)
canvas.create_window((0, 0), window=scrollable_inner, anchor="nw")
canvas.configure(yscrollcommand=scrollbar.set)

scrollbar.pack(side=tk.RIGHT, fill=tk.Y)
canvas.pack(side=tk.LEFT, fill=tk.BOTH, expand=True)

# _add_card() は scrollable_inner を渡す（notify_frame ではなく）
notify_content = self._add_card(scrollable_inner, colors)
```

マウスホイールでスクロールできるよう、Canvas にバインドを追加することを推奨する：

```python
canvas.bind_all("<MouseWheel>", lambda e: canvas.yview_scroll(int(-1*(e.delta/120)), "units"))
```

ただし `bind_all` はグローバルに効くため、他のタブでもスクロールが発火することに注意。
別タブのスクロールを防ぐ実装（タブ切り替え時に bind/unbind 等）は Eng の判断に委ねる。
