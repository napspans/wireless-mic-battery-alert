# Step 8: 全体レイアウト・余白の統一

## 目的
`gui.py` のウィンドウ構造・余白・波形エリアを Apple HIG 精神に基づいて改善する。
`theme.py` の `COLORS` / `FONTS` / `get_colors()` を活用し、
空間設計（余白・パディング）と波形エリアのスタイルを刷新する。

## 作業対象ファイル
- `wireless-mic-battery-alert-eng/gui.py`

## 変更仕様

### 1. パディング定数の定義
ファイル冒頭（import 直後）に以下の定数を定義し、全体で統一して使用する：
- `_PAD_OUTER = 16` — ウィンドウ端からの余白
- `_PAD_INNER = 8` — セクション内の余白
- `_PAD_ROW = (6, 6)` — 行間の上下余白

### 2. ウィンドウサイズの調整
- `self._root.geometry("640x720")` に変更（余白増加分を吸収）

### 3. 波形エリアのレイアウト改善（`_build_waveform_area`）
- `waveform_frame` の `padx` / `pady` を `_PAD_OUTER` を使って設定
  - `padx=_PAD_OUTER`, `pady=(_PAD_OUTER, 0)`
- `FigureCanvasTkAgg` の `figsize` を `(5.8, 2.2)` に調整
- ズームボタンのパディングを `padx=_PAD_INNER, pady=(0, 4)` に統一

### 4. ステータスラベルのデザイン改善
- `tk.Label` を `ttk.Label` に変更
- フォントを `theme.FONTS["caption"]` に変更
- `padx` を `_PAD_OUTER` に統一

### 5. グラフテーマ適用の改善（`_apply_graph_theme`）
- ライト/ダークのカラーを `from theme import get_colors` を使って参照
  - `bg` → `colors["surface"]`
  - `fg` → `colors["label"]`
  - `spine_color` → `colors["border"]`

### 6. `__init__` 内の `apply_theme` 呼び出し後に背景色を設定
- `self._root.configure(background=get_colors(resolved_theme)["bg"])` を追加
  - `resolved_theme` は `"system"` の場合 `get_system_theme()` で解決した値

## インターフェース制約
- 外部インターフェース（`SettingsGUI` のコンストラクタシグネチャ）は変更しない
- `_apply_graph_theme(theme: str)` のシグネチャも変更しない

## 完了条件
- [ ] `_PAD_OUTER`, `_PAD_INNER`, `_PAD_ROW` が定義されている
- [ ] 波形エリアの `padx`/`pady` が定数を使って設定されている
- [ ] ステータスラベルが `ttk.Label` に変更されている
- [ ] `_apply_graph_theme` が `get_colors()` を使ってカラーを参照している
- [ ] `self._root` に `background` が設定されている
- [ ] `python3 -m py_compile gui.py` が成功する

## 注意事項
- フォーム部分（タブ内のラベル・入力欄）はStep 9で対応するため、変更しない
- ボタンエリアはStep 10で対応するため、変更しない
- `FONTS` は `theme.FONTS` としてモジュール参照で使用すること（`from theme import FONTS` でも可）
