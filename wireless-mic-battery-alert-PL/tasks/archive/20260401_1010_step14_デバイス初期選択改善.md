# Step 14: 入力デバイス選択の改善（既定デバイスの表示と初期選択）

## 目的
実機テストで「デバイスが多すぎてどれを選べばよいか分からない」という問題を解消する。
OSの既定入力デバイスを明示し、未設定時は既定デバイスが自動選択された状態にする。

## 作業対象ファイル
- `wireless-mic-battery-alert-eng/monitor.py`
- `wireless-mic-battery-alert-eng/gui.py`

## 変更仕様

### monitor.py: list_input_devices() の改修
`sd.default.device` からデフォルト入力デバイスのインデックスを取得し、
該当デバイスの name に `（既定）` を付与して返す。
戻り値の各辞書に `is_default: bool` フィールドを追加する。

- `sd.default.device` はタプル `(input_index, output_index)` を返す
- 既定デバイスが存在しない場合（None または -1）は `is_default: False` で通常通り返す

### gui.py: デバイスの初期選択ロジックの改修
設定に `device_index` が保存されていない場合（新規起動時など）、
`is_default: True` のデバイスをコンボボックスの初期選択にする。

現在の実装（`gui.py` 130〜136行あたり）:
- 保存済み `device_index` がある場合 → 該当デバイスを選択（既存動作を維持）
- 保存済み `device_index` がない場合 → `is_default: True` のデバイスを選択（変更点）
  - 既定デバイスが見つからない場合はインデックス0のデバイスを選択（フォールバック）

## インターフェース制約
`list_input_devices()` の戻り値の型:

```python
list[dict]  # 各要素: {"index": int, "name": str, "is_default": bool}
```

gui.py 側はこの `is_default` フィールドを参照して初期選択を決定すること。

- デバイス名の変更（`（既定）` 付与）は `monitor.py` 側で行い、`gui.py` では名前をそのまま表示すること
