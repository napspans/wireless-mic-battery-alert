# Step 17: ラベル背景色修正 (ttk→tk.Label)

## 目的

設定画面の各項目ラベルが「選択済み」のようにハイライトされて見える問題を修正する。

`sv_ttk` テーマ適用時、`ttk.Label` のテーマ背景色と親フレーム（`tk.Frame`）の背景色がわずかに異なるため、ラベルだけが浮いて見える。`tk.Label` に差し替え背景色を明示することで解消する。

## 作業対象ファイル

- `wireless-mic-battery-alert-eng/gui.py`

## 変更仕様

以下の2点を変更する。

### 1. ラベル生成メソッドの修正

`_make_body_label()` および `_make_headline_label()` 内の `ttk.Label` を `tk.Label` に変更する。
`font=` と `foreground=` は直接引数で指定し、`background=colors["surface"]` を明示的に設定する。

### 2. テーマ切替時の背景色再設定

`_apply_visual_theme()` 内で `_headline_labels` および `_body_labels` を走査するループにおいて、`foreground` の再設定に加えて `background=colors["surface"]` も再設定するよう変更する。

## インターフェース制約

`_make_body_label()` / `_make_headline_label()` の呼び出し側シグネチャは変更しない:
```
def _make_body_label(self, parent, text: str, colors: dict, **grid_kwargs)
def _make_headline_label(self, parent, text: str, colors: dict, **grid_kwargs)
```

## 完了条件

- [ ] `_make_body_label()` および `_make_headline_label()` が `tk.Label` を使用している
- [ ] 両メソッドで `background=colors["surface"]` が明示的に設定されている
- [ ] `_apply_visual_theme()` のラベル走査ループで `background` も再設定されている
- [ ] `ttk.Label` への参照が両メソッドから除去されている

## 注意事項

- `_body_labels` / `_headline_labels` リストへの追加ロジックは変更しない
- 内部実装はEngに委ねる
