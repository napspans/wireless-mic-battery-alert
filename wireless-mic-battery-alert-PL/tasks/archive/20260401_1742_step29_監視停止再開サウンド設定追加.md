# Step 29: 監視停止・再開サウンド設定追加

## 目的

現在 `main.py._toggle_monitor()` の停止・開始サウンドが `"builtin:notify_11"` 固定になっている。
このステップでは、サウンドファイルと有効/無効をユーザーが設定できるようにし、
GUIの監視ボタンからもサウンド付きトグルが動作するよう改修する。

## 作業対象ファイル

- `wireless-mic-battery-alert-eng/settings.py`
- `wireless-mic-battery-alert-eng/gui.py`
- `wireless-mic-battery-alert-eng/main.py`

## 変更仕様

### 1. settings.py — デフォルト設定追加

`DEFAULT_CONFIG` に以下4項目を追加する:

```
monitor_stop_sound_enabled: True
monitor_stop_sound_path: "builtin:notify_11"
monitor_resume_sound_enabled: True
monitor_resume_sound_path: "builtin:notify_11"
```

### 2. gui.py — 通知設定タブにセクション追加

通知設定タブの「一時停止サウンド」セクションの**後ろ**に、以下の2セクションを追加する。

#### 「監視停止サウンド」セクション

- ヘッドライン「監視停止サウンド」
- 行: チェックボックス「有効にする」（`monitor_stop_sound_enabled`）
- 行: サウンドファイル選択（コンボボックス＋テスト再生ボタン）
  - 選択肢は `_PAUSE_SOUND_OPTIONS` と同じものを使用
  - カスタム選択時はファイルパス入力欄＋参照ボタンを表示
- チェックボックスOFF時は選択UIを disabled にする
- チェックボックスは `_make_checkbutton()` を使用（Step 28と同方式）

#### 「監視再開サウンド」セクション

- ヘッドライン「監視再開サウンド」
- 行: チェックボックス「有効にする」（`monitor_resume_sound_enabled`）
- 行: サウンドファイル選択（コンボボックス＋テスト再生ボタン）
  - 選択肢は `_PAUSE_SOUND_OPTIONS` と同じものを使用
  - カスタム選択時はファイルパス入力欄＋参照ボタンを表示
- チェックボックスOFF時は選択UIを disabled にする
- チェックボックスは `_make_checkbutton()` を使用

#### `_on_save()` への追記

以下の4項目を `_on_save()` の保存処理に追加する:

```
self._config["monitor_stop_sound_enabled"]
self._config["monitor_stop_sound_path"]
self._config["monitor_resume_sound_enabled"]
self._config["monitor_resume_sound_path"]
```

### 3. gui.py — on_toggle_monitor コールバック追加

#### `__init__()` の変更

- 引数に `on_toggle_monitor: callable | None = None` を追加
- `self._on_toggle_monitor = on_toggle_monitor` として保持

#### `_toggle_monitor()` の変更

- コールバックが渡されている場合は `self._on_toggle_monitor()` を呼び、処理を委譲する
- コールバックが渡されていない場合は現状の動作（`self._monitor.start()` / `stop()` を直接呼ぶ）を維持する

### 4. main.py — _toggle_monitor() のサウンドパス修正

- 停止時: `self._config.get("monitor_stop_sound_enabled", True)` が True の場合のみ、`self._config.get("monitor_stop_sound_path", "builtin:notify_11")` を再生する
- 開始時: `self._config.get("monitor_resume_sound_enabled", True)` が True の場合のみ、`self._config.get("monitor_resume_sound_path", "builtin:notify_11")` を再生する

#### `_run_gui()` の変更

`SettingsGUI(...)` の呼び出しに `on_toggle_monitor=self._toggle_monitor` を追加する。

## インターフェース制約

`SettingsGUI.__init__()` のシグネチャ:

```python
def __init__(
    self,
    monitor: AudioMonitor,
    config: dict,
    on_config_save: callable,
    on_toggle_monitor: callable | None = None,
):
```

- [ ] 通知設定タブに「監視停止サウンド」「監視再開サウンド」セクションが表示される
- [ ] 各セクションのチェックボックスOFF時にサウンド選択UIが disabled になる
- [ ] 各セクションのチェックボックスは `_make_checkbutton()` を使用し、テーマ追従する
- [ ] `_on_save()` が新4項目を保存する
- [ ] GUI監視ボタンを押すと `main.py._toggle_monitor()` が呼ばれ、サウンドが鳴る
- [ ] 停止サウンドをOFFにした状態で監視停止すると、サウンドが鳴らない
- [ ] 再開サウンドをOFFにした状態で監視開始すると、サウンドが鳴らない
- [ ] 設定はアプリ再起動後も維持される

## 動作確認手順

1. アプリを起動する
2. 設定画面を開き、通知設定タブを確認する
3. 「監視停止サウンド」「監視再開サウンド」セクションが表示されることを確認する
4. 監視ボタンで停止→開始を繰り返し、各サウンドが鳴ることを確認する
5. 停止サウンドをOFFにして監視停止 → サウンドが鳴らないことを確認する
6. アプリを再起動して設定が維持されることを確認する

## 注意事項

- コールバックなし（`on_toggle_monitor=None`）の場合の後退互換性を維持すること
- `_on_save()` への追加4項目が漏れないこと
- Step 28で追加した `_make_checkbutton()` 方式を踏襲すること（テーマ追従のため）
